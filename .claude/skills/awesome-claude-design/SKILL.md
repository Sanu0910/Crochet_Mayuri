# Awesome Claude Design

Local copy of https://github.com/rohitg00/awesome-claude-design.

1. **Pick a family** in `design-md/` that fits the brand. Each folder has a
   DESIGN.md with colour, type, spacing and component rules. `prompts/family-picker.md`
   helps choose.
2. **Follow a recipe** in `recipes/` for the job: landing page in 20 minutes,
   brand extraction, wireframe to hi-fi, pitch deck from a README, and others.
3. **Use a prompt** in `prompts/` to push past the default look:
   `break-default-aesthetic.md`, `3-designer-debate.md`, `audit-live-site.md`,
   `brand-to-design-md.md`, `remix-two-brands.md`.

Read the relevant files before designing; don't paste them wholesale.
